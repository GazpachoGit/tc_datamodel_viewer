## Общая модель

Модель данных является рекомендацией и может расширяться в процессе
разработки. При каждом таком расширении необходимо обновлять этот файл.

- **DM1.** Состав модели:

  ```text
  Model
    classes: классы по имени

  Class
    name: имя
    parent: имя родителя
    attributes: атрибуты по имени
    compounds: compound-свойства по имени
    relations: имена relation-классов
    grm_rules: GRM-правила

  Attribute
    name: имя
    type: тип PlantUML
    is_array: признак массива
    array_flag: XML-имя и исходное значение признака массива
    chars: характеристики

  Compound
    name: имя (destPropertyName)
    type: отображаемый тип из маппинга
    chars: характеристики

  GRMRule
    chars: характеристики (по маппингу TcGRMRule)
  ```

- **DM2.** Назначение полей:
  - `Model` — общая модель данных из всех входных файлов.
    - `classes` — словарь, где ключ — имя класса, а значение — объект `Class`.
      Обеспечивает поиск по имени в среднем за O(1) и объединение классов.
  - `Class` — представление одного UML-класса.
    - `name` — объявление класса и сообщения об ошибках.
    - `parent` — построение связи наследования и обнаружение конфликтующих
      родителей (инвалидный вход, IV2).
    - `attributes` — добавление атрибутов и обнаружение повторов
      (инвалидный вход, IV1).
    - `compounds` — добавление compound-свойств и обнаружение повторов;
      имена уникальны в объединённом пространстве имён атрибутов и
      compound-свойств класса (IV1).
    - `relations` — множество имён relation-классов, свойствами которых
      владеет этот класс как primary (NF9). Имя relation-свойства всегда
      равно имени relation-класса и ссылается на обычный `Class` в
      `Model.classes`. Используется для построения пунктирных рёбер диаграммы
      и обнаружения повторов пары (инвалидный вход, IV5).
    - `grm_rules` — упорядоченный список записей `GRMRule` этого
      relation-класса (NF10); обнаружение повторов по составному
      идентификатору primaryTypeName + secondaryTypeName + conditionName
      (инвалидный вход, IV6); вывод в панели свойств по AR3. Отдельного
      реестра правил на уровне `Model` нет.
  - `Attribute` — представление одного атрибута UML-класса.
    - `name` — вывод имени и обнаружение повторов.
    - `type` — вывод типа PlantUML из маппинга.
    - `is_array` — добавление `[]` к типу массива.
    - `array_flag` — вывод признака массива в панели свойств под исходным
      XML-именем (AR1).
    - `chars` — вывод XML-имён и значений характеристик в скобках.
  - `Compound` — представление одного compound-свойства UML-класса
    (из `TcCompoundPropertyRule`).
    - `name` — вывод имени и обнаружение повторов.
    - `type` — вывод отображаемого типа из маппинга.
    - `chars` — вывод XML-имён и значений характеристик (путь `pathToSource`).
  - `GRMRule` — форма одной записи списка `grm_rules` (не глобальный реестр),
    из `TcGRMRule`.
    - `chars` — вывод XML-имён и значений характеристик по маппингу
      `TcGRMRule` (`primaryTypeName`, `secondaryTypeName`, `conditionName`,
      `primaryCardinality`, `secondaryCardinality`).
