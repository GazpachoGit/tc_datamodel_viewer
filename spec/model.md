## Общая модель

Модель данных является рекомендацией и может расширяться в процессе
разработки. При каждом таком расширении необходимо обновлять этот файл.

- **DM1.** Состав модели:

  ```text
  Model
    classes: классы по имени

  Class
    name: имя
    parent: имя родителя
    attributes: атрибуты по имени

  Attribute
    name: имя
    type: тип PlantUML
    is_array: признак массива
    array_flag: XML-имя и исходное значение признака массива
    chars: характеристики
  ```

- **DM2.** Назначение полей:
  - `Model` — общая модель данных из всех входных файлов.
    - `classes` — словарь, где ключ — имя класса, а значение — объект `Class`.
      Обеспечивает поиск по имени в среднем за O(1) и объединение классов.
  - `Class` — представление одного UML-класса.
    - `name` — объявление класса и сообщения об ошибках.
    - `parent` — построение связи наследования и обнаружение конфликтующих
      родителей (инвалидный вход, IV2).
    - `attributes` — добавление атрибутов и обнаружение повторов
      (инвалидный вход, IV1).
  - `Attribute` — представление одного атрибута UML-класса.
    - `name` — вывод имени и обнаружение повторов.
    - `type` — вывод типа PlantUML из маппинга.
    - `is_array` — добавление `[]` к типу массива.
    - `array_flag` — вывод признака массива в панели свойств под исходным
      XML-именем (AR1).
    - `chars` — вывод XML-имён и значений характеристик в скобках.
